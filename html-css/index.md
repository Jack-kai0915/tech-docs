# HTML & CSS 学习手册

## 什么是 HTML & CSS

**HTML**（HyperText Markup Language）是网页的结构语言，定义内容的语义。
**CSS**（Cascading Style Sheets）是网页的样式语言，控制外观和布局。

## 核心价值

- **语义化结构**：让内容有意义
- **响应式设计**：适配各种设备
- **动画交互**：提升用户体验
- **性能优化**：流畅的视觉效果

## 学习路线

### 📚 CSS 基础
选择器、盒模型、颜色、字体

### 📐 布局系统
Flexbox、Grid、定位、响应式

### 🎨 动画效果
过渡、关键帧、3D 变换、物理动画

### ✨ 特效实现
玻璃拟态、渐变、阴影、滤镜
