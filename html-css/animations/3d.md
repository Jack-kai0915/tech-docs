# 3D 变换

## 什么是 3D 变换

CSS 3D 变换让元素可以在三维空间中旋转、移动和缩放。

### 基本概念

```
          Y 轴 (向上)
            ↑
            │
            │
            │
            │
X 轴 ←──────┼──────→ X 轴
            │
            │
            │
            ↓
          Y 轴 (向下)

Z 轴: 垂直于屏幕，指向观察者
```

---

## 3D 变换函数

### perspective

```css
/* 设置透视点距离 */
.container {
  perspective: 1000px;
}

/* 或者在元素上设置 */
.element {
  transform: perspective(1000px) rotateY(45deg);
}
```

**图解：**

```
透视点距离越小，透视效果越强：

perspective: 500px        perspective: 1000px
    ┌─────┐                  ┌─────────┐
   ╱│     │╲                ╱│         │╲
  ╱ │     │ ╲              ╱ │         │ ╲
 ╱  │     │  ╲            ╱  │         │  ╲
    └─────┘                  └─────────┘
```

### rotateX / rotateY / rotateZ

```css
/* 绕 X 轴旋转 */
.element {
  transform: rotateX(45deg);
}

/* 绕 Y 轴旋转 */
.element {
  transform: rotateY(45deg);
}

/* 绕 Z 轴旋转（等同于 2D 旋转） */
.element {
  transform: rotateZ(45deg);
}

/* 组合旋转 */
.element {
  transform: rotateX(45deg) rotateY(45deg) rotateZ(45deg);
}
```

**图解：**

```
rotateX(45deg):
    ┌─────────┐
    │         │  ← 向后倾斜
    └─────────┘

rotateY(45deg):
      ╱─────╱
     ╱     ╱
    ╱─────╱  ← 向右旋转

rotateZ(45deg):
        ╱───╱
       ╱   ╱
      ╱───╱  ← 平面旋转
```

### translateZ

```css
/* 沿 Z 轴移动 */
.element {
  transform: translateZ(100px);  /* 向观察者移动 */
}

.element {
  transform: translateZ(-100px);  /* 远离观察者 */
}
```

### scaleZ

```css
/* 沿 Z 轴缩放 */
.element {
  transform: scaleZ(2);  /* 沿 Z 轴放大 2 倍 */
}
```

## 3D 变换实战

### 1. 3D 卡片翻转

```css
.flip-card {
  width: 300px;
  height: 200px;
  perspective: 1000px;
}

.flip-card-inner {
  position: relative;
  width: 100%;
  height: 100%;
  transition: transform 0.6s;
  transform-style: preserve-3d;
}

.flip-card:hover .flip-card-inner {
  transform: rotateY(180deg);
}

.flip-card-front,
.flip-card-back {
  position: absolute;
  width: 100%;
  height: 100%;
  backface-visibility: hidden;
  border-radius: 12px;
  display: flex;
  align-items: center;
  justify-content: center;
  font-size: 24px;
}

.flip-card-front {
  background: linear-gradient(135deg, #667eea, #764ba2);
  color: white;
}

.flip-card-back {
  background: linear-gradient(135deg, #f093fb, #f5576c);
  color: white;
  transform: rotateY(180deg);
}
```

**效果：**

```
正面 (悬停前):          背面 (悬停后):
┌──────────────┐       ┌──────────────┐
│              │       │              │
│   Front      │  →    │    Back      │
│              │       │              │
└──────────────┘       └──────────────┘
    旋转 180°
```

### 2. 3D 立方体

```css
.cube-container {
  width: 200px;
  height: 200px;
  perspective: 600px;
}

.cube {
  width: 100%;
  height: 100%;
  position: relative;
  transform-style: preserve-3d;
  animation: rotate-cube 10s linear infinite;
}

@keyframes rotate-cube {
  0% { transform: rotateX(0) rotateY(0); }
  100% { transform: rotateX(360deg) rotateY(360deg); }
}

.cube-face {
  position: absolute;
  width: 200px;
  height: 200px;
  border: 2px solid rgba(255,255,255,0.5);
  display: flex;
  align-items: center;
  justify-content: center;
  font-size: 24px;
  color: white;
}

.front  { background: rgba(255,0,0,0.7); transform: translateZ(100px); }
.back   { background: rgba(0,255,0,0.7); transform: rotateY(180deg) translateZ(100px); }
.right  { background: rgba(0,0,255,0.7); transform: rotateY(90deg) translateZ(100px); }
.left   { background: rgba(255,255,0,0.7); transform: rotateY(-90deg) translateZ(100px); }
.top    { background: rgba(255,0,255,0.7); transform: rotateX(90deg) translateZ(100px); }
.bottom { background: rgba(0,255,255,0.7); transform: rotateX(-90deg) translateZ(100px); }
```

**效果：**

```
      ┌─────────┐
     ╱│        ╱│
    ╱ │       ╱ │
   ┌─────────┐  │
   │  │      │  │
   │  └──┬───│──┘
   │ ╱   │   │ ╱
   └─────┴───┘
      立方体旋转
```

### 3. 3D 旋转菜单

```css
.menu-3d {
  width: 200px;
  height: 200px;
  perspective: 500px;
  position: relative;
}

.menu-3d-item {
  position: absolute;
  width: 100%;
  padding: 15px;
  background: #3b82f6;
  color: white;
  text-align: center;
  border-radius: 8px;
  transform-origin: center center;
  transition: transform 0.3s ease;
}

.menu-3d:hover .menu-3d-item:nth-child(1) {
  transform: rotateX(-60deg) translateZ(50px);
}

.menu-3d:hover .menu-3d-item:nth-child(2) {
  transform: rotateX(-30deg) translateZ(80px);
}

.menu-3d:hover .menu-3d-item:nth-child(3) {
  transform: rotateX(0deg) translateZ(100px);
}

.menu-3d:hover .menu-3d-item:nth-child(4) {
  transform: rotateX(30deg) translateZ(80px);
}
```

## 3D 变换最佳实践

```css
/* 1. 使用 transform-style: preserve-3d */
.parent {
  transform-style: preserve-3d;
}

/* 2. 设置合理的 perspective */
.container {
  perspective: 800px;  /* 推荐 600-1000px */
}

/* 3. 使用 backface-visibility: hidden */
.card {
  backface-visibility: hidden;
}

/* 4. 使用 will-change 提示浏览器 */
.animated-3d {
  will-change: transform;
}

/* 5. 性能优化 */
/* 避免在动画中使用 box-shadow */
/* 使用 filter: drop-shadow() 代替 */
```
