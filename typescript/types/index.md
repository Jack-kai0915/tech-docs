# 类型系统

TypeScript 的核心是其强大的类型系统，帮助你在编译时捕获错误。

## 内容概览

- [基本类型](/typescript/types/primitives) - string、number、boolean 等基本类型
- [接口](/typescript/types/interfaces) - 定义对象的结构
- [泛型](/typescript/types/generics) - 创建可复用的类型安全组件
- [枚举](/typescript/types/enums) - 定义命名常量集合
- [类型别名](/typescript/types/aliases) - 创建类型的新名称
