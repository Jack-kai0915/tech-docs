# TypeScript 学习手册

## 什么是 TypeScript

TypeScript 是 JavaScript 的超集，添加了静态类型系统，提供更好的开发体验和代码质量保障。

## 核心优势

- **静态类型检查**：在编译时发现错误，而非运行时
- **智能代码提示**：IDE 提供精准的自动补全和文档
- **更好的重构**：类型系统让代码重构更安全
- **团队协作**：类型即文档，降低沟通成本

## 学习路线

### 📚 基础语法
环境搭建、变量、数据类型、运算符、字符串操作、条件语句、循环语句

### 🗂️ 类型系统
基本类型、接口、泛型、枚举、类型别名、工具类型

### ⚡ 面向对象
类、继承、访问修饰符、抽象类、装饰器

### 🔄 异步编程
Promise、async/await、异步迭代、并发控制

### 📦 模块系统
ES 模块、命名空间、模块解析

### 🚀 框架实战
Vue3 + TypeScript、React + TypeScript

### 🔧 进阶内容
高级类型、类型体操、设计模式、性能优化
