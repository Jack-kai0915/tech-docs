# Vue3 vs React 对比教学

## 什么是本文档

本文档面向有 HTML/CSS/JS 基础、想深入现代前端框架的开发者，通过对比方式同时学习 Vue3 和 React。

## 目标读者

- 会用 HTML/CSS/JavaScript 基础
- 未深入接触过现代前端框架
- 想同时掌握 Vue3 和 React 两大主流框架

## 文档结构

| 章节 | 内容 | 难度 |
|------|------|------|
| [第一章：认识框架](/vue-react/chapter1) | 设计哲学、项目初始化、目录结构 | ⭐ |
| [第二章：组件基础](/vue-react/chapter2) | 组件定义、Props、事件、插槽 | ⭐⭐ |
| [第三章：状态管理](/vue-react/chapter3) | 本地状态、计算属性、全局状态 | ⭐⭐ |
| [第四章：生命周期](/vue-react/chapter4) | 生命周期钩子、副作用处理 | ⭐⭐⭐ |
| [第五章：路由](/vue-react/chapter5) | Vue Router vs React Router | ⭐⭐⭐ |
| [第八章：避坑指南](/vue-react/chapter8) | 常见陷阱与最佳实践 | ⭐⭐⭐⭐ |

## 代码规范

- Vue3 使用 `<script setup>` 语法
- React 使用函数组件 + Hooks
- 使用 TypeScript
- 代码包含详细注释

## 快速开始

```bash
# 创建 Vue3 项目
npm create vue@latest my-vue-app

# 创建 React 项目
npm create vite@latest my-react-app -- --template react-ts
```
