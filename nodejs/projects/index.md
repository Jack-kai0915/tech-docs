# 实战项目

通过实战项目巩固 Node.js 知识，提升实战能力。

## 项目列表

### 🛒 电商平台 API
Express + MongoDB 构建完整电商后端

### 💬 实时聊天应用
Socket.IO 实现实时通信

### 📝 博客系统
Express + SQLite 构建博客平台

### 🔐 用户认证系统
JWT + bcrypt 实现安全认证

### 📊 数据看板 API
NestJS 构建数据分析服务

### 🔄 任务调度系统
Bull + Redis 实现异步任务

## 项目结构

每个项目包含：
- 完整源代码
- 项目说明
- 启动方式
- API 文档
