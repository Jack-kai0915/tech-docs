## 核心术语详解

### 1. 模型相关

| 术语 | 英文 | 解释 | 类比 |
|------|------|------|------|
| **模型** | Model | 从数据中学到的规律 | 大脑 |
| **参数** | Parameters | 模型内部的数字 | 神经连接 |
| **权重** | Weights | 参数的一种 | 连接强度 |
| **推理** | Inference | 使用模型预测 | 思考过程 |
| **训练** | Training | 调整参数的过程 | 学习过程 |

### 2. 数据相关

| 术语 | 英文 | 解释 | 示例 |
|------|------|------|------|
| **特征** | Feature | 输入数据的属性 | 房价预测中的"面积" |
| **标签** | Label | 监督学习的目标值 | 图片中的"猫" |
| **数据集** | Dataset | 用于训练的数据集合 | ImageNet |
| **批大小** | Batch Size | 每次处理的样本数 | 32、64、128 |
| **Epoch** | Epoch | 完整遍历数据集一次 | 训练 10 个 epoch |

### 3. 训练相关

| 术语 | 英文 | 解释 | 影响 |
|------|------|------|------|
| **损失函数** | Loss Function | 衡量预测与真实值的差距 | 越小越好 |
| **优化器** | Optimizer | 更新参数的算法 | Adam、SGD |
| **学习率** | Learning Rate | 参数更新的步长 | 太大会震荡，太小会慢 |
| **过拟合** | Overfitting | 过度记忆训练数据 | 测试集表现差 |
| **欠拟合** | Underfitting | 未能捕捉规律 | 训练集表现差 |

### 4. LLM 相关

| 术语 | 英文 | 解释 | 示例 |
|------|------|------|------|
| **Token** | Token | 文本的最小单位 | "你好" → 2 tokens |
| **Prompt** | Prompt | 输入给模型的指令 | "写一首诗" |
| **Temperature** | Temperature | 控制输出随机性 | 0=确定，1=随机 |
| **Context Window** | 上下文窗口 | 模型能处理的最大长度 | 4K、8K、128K |
| **Fine-tuning** | 微调 | 在特定数据上继续训练 | 领域适配 |

## 常见问题

### Q1: 机器学习和深度学习的区别？

**机器学习**：更广泛的概念，包含各种算法（决策树、SVM、随机森林等）

**深度学习**：机器学习的子集，专门使用多层神经网络

```
机器学习
├── 传统算法（决策树、SVM...）
└── 深度学习
    ├── CNN（图像）
    ├── RNN/LSTM（序列）
    └── Transformer（NLP、多模态）
```

### Q2: LLM 是如何工作的？

1. **Tokenization**：将文本分割成 tokens
2. **Embedding**：将 tokens 转换为向量
3. **Transformer 处理**：通过多层注意力机制
4. **输出概率**：预测下一个 token 的概率
5. **采样生成**：根据概率选择输出

### Q3: 什么是 RAG？

**RAG (Retrieval-Augmented Generation)** = 检索 + 生成

```
用户问题 → 向量检索相关文档 → 将文档作为上下文 → LLM 生成回答
```

**优势**：
- 减少幻觉
- 知识可更新
- 可追溯来源
