# AI 发展简史

## 第一阶段：萌芽期（1950s-1970s）

### 图灵测试与 AI 概念诞生

**1950年** - 艾伦·图灵发表《计算机器与智能》，提出著名的**图灵测试**：
- 如果一台机器的行为与人类无法区分，则可认为它具有智能
- 这成为衡量 AI 的经典标准

**1956年** - 达特茅斯会议
- 约翰·麦卡锡首次提出"人工智能"术语
- 标志着 AI 作为独立学科的诞生
- 参与者：麦卡锡、明斯基、香农、纽厄尔

### 早期成就

| 年份 | 事件 | 意义 |
|------|------|------|
| 1956 | 逻辑理论机 | 首个 AI 程序，证明数学定理 |
| 1957 | 感知机 | 首个神经网络模型 |
| 1966 | ELIZA | 首个聊天机器人 |
| 1968 | SHURDLU | 首个自然语言理解程序 |

### 第一次寒冬（1974-1980）

**原因**：
- 计算能力不足
- 算法局限性
- 过度乐观导致失望

## 第二阶段：专家系统（1980s）

### 专家系统的兴起

**核心思想**：将领域专家的知识编码成规则

```python
# 专家系统示例
rules = {
    "发烧+咳嗽": "可能感冒",
    "发烧+皮疹": "可能过敏",
    "头痛+视力模糊": "可能偏头痛"
}

def diagnose(symptoms):
    for rule, diagnosis in rules.items():
        if all(s in symptoms for s in rule.split("+")):
            return diagnosis
    return "无法诊断"
```

**成功案例**：
- MYCIN：医疗诊断系统
- DENDRAL：化学分析系统
- R1/XCON：计算机配置系统

### 第二次寒冬（1987-1993）

**原因**：
- 专家系统维护成本高
- 知识获取瓶颈
- PC 普及冲击大型机

## 第三阶段：机器学习复兴（1990s-2010s）

### 关键突破

**1997年** - IBM 深蓝击败国际象棋冠军卡斯帕罗夫

**2006年** - 杰弗里·辛顿提出深度学习
- 反向传播算法优化
- 多层神经网络训练

**2011年** - IBM Watson 击败 Jeopardy! 冠军

### 重要算法发展

| 算法 | 年份 | 应用 |
|------|------|------|
| 支持向量机 (SVM) | 1995 | 分类、回归 |
| 随机森林 | 2001 | 集成学习 |
| LSTM | 1997 | 序列建模 |
| 卷积神经网络 (CNN) | 2012 | 图像识别 |
| 生成对抗网络 (GAN) | 2014 | 图像生成 |

---

## 第四阶段：深度学习革命（2012-2020）

### ImageNet 竞赛的突破

**2012年** - AlexNet 在 ImageNet 竞赛中大获全胜
- 错误率从 26% 降到 16%
- 证明深度学习的有效性
- 开启计算机视觉新纪元

### 重要里程碑

**2014年** - 生成对抗网络 (GAN)
- Ian Goodfellow 提出
- 可以生成逼真的图像
- 应用：人脸生成、图像修复

**2016年** - AlphaGo 击败李世石
- 深度强化学习的胜利
- AI 在复杂策略游戏中的突破
- 引发全球 AI 热潮

**2017年** - Transformer 架构诞生
- Google 论文《Attention Is All You Need》
- 自注意力机制
- 成为后续大模型的基础

---

## 第五阶段：大语言模型时代（2020-至今）

### GPT 系列的崛起

**2020年** - GPT-3 发布
- 1750 亿参数
- 展示 few-shot learning 能力
- 生成质量大幅提升

**2022年** - ChatGPT 发布
- 对话式 AI 的里程碑
- 2 个月用户破亿
- 引发 AI 应用爆发

**2023年** - GPT-4 发布
- 多模态能力（文本+图像）
- 更强的推理能力
- 更高的准确性

### 其他重要模型

| 模型 | 公司 | 特点 |
|------|------|------|
| Claude | Anthropic | 安全、可控 |
| Gemini | Google | 多模态 |
| Llama | Meta | 开源 |
| Mistral | Mistral AI | 高效 |
| DeepSeek | 深度求索 | 推理能力强 |

### 多模态 AI 的兴起

**2023-2024年** - 多模态成为趋势
- 文本 → 图像：DALL-E、Midjourney、Stable Diffusion
- 文本 → 视频：Sora、Runway
- 文本 → 音乐：Suno、Udio
- 图像 → 文本：GPT-4V、Claude Vision
